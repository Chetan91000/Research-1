# Repository Setup

This repository contains the research project.

## Note on Large Files
GitHub enforces a strict 100 MB file size limit per file. Due to this restriction, the `ieee/miktex-setup.exe` file (which is ~142 MB) has been explicitly excluded from this repository via `.gitignore` to prevent push errors.

If you need to install MiKTeX to compile the IEEE paper locally, please download the setup executable directly from the [official MiKTeX website](https://miktex.org/download) rather than pulling it from this repository.
